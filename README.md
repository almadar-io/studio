# Almadar Studio Website

Marketing and documentation website for [Almadar Studio](https://studio.almadar.io) — Build software with AI.

Built with [Docusaurus](https://docusaurus.io/).

## Development

```bash
npm install
npm start
```

## Build

```bash
npm run build
```

## Deploy

Deploys automatically to Firebase Hosting on push to `main`.

```bash
npm run deploy
```
